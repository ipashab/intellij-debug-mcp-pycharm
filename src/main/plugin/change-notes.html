0.2.1-pycharm

  • PyCharm build: removed the hard dependency on the Java plugin, so the plugin loads in PyCharm 2026.1.
  • Removed Java-only tools: decompile_class; set_breakpoint/remove_breakpoint now take filePath only.
  • 18 MCP tools targeting the generic XDebugger API (Python and other languages).

0.2.0

  • Made the plugin lighter and reduced thirdparty dependencies.

0.1.0

  • Initial release.
  • 19 MCP tools: run configs, breakpoints, execution control, variable inspection, expression evaluation, console I/O, class decompilation, process info.
  • TCP server with dynamic or fixed port (configurable in the Debug MCP tool window).
  • Auto-start on project open; port written to .idea/debugmcp.port.
  • Bundled debugmcp-proxy.cmd cross-platform stdio proxy (Kotlin/JVM) for native MCP integration.
  • Ready-to-copy MCP configuration snippet in the tool window.
