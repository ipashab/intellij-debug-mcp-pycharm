Debug MCP Server (PyCharm)

Exposes an MCP (Model Context Protocol) server from PyCharm so AI coding assistants (OpenCode, Claude Code, Windsurf Cascade, Cursor, etc.) can control the debugger remotely.

Highlights

  • Starts automatically when the project opens — zero-config by default.
  • Includes a bundled stdio proxy so MCP clients work even if PyCharm starts after the AI agent.
  • Supports dynamic (auto-assigned) or fixed TCP port via the settings panel.
  • Port is written to <project>/.idea/debugmcp.port for auto-discovery.

Connecting

The recommended setup uses the bundled stdio proxy (bin/debugmcp-proxy.cmd inside the plugin directory). Add this to your MCP client configuration:

{
  "mcpServers": {
    "pycharm-debug": {
      "command": "<plugin-dir>/bin/debugmcp-proxy.cmd"
    }
  }
}

The proxy handles boot-ordering: it starts immediately and connects to PyCharm on demand. Open the Debug MCP tool window to see the exact paths and a ready-to-copy config snippet.

Available Tools (18)

Run Configslist_run_configurations, start_debug_session, stop_debug_session, get_debug_status
Breakpointsset_breakpoint, remove_breakpoint, list_breakpoints
Executionresume, step_over, step_into, step_out
Inspectionget_threads, get_stack_trace, get_variables, evaluate_expression, get_console_output, send_console_input
Processget_process_info

set_breakpoint and remove_breakpoint accept filePath (local source, absolute path).

All execution/inspection tools accept an optional sessionName to target a specific debug session, and an optional port to route to a specific IDE instance.
